# ADR-0012: 日本語役一覧へUM+ BDFフォントを同梱する

- 状態: 採用
- 日付: 2026-07-25
- 使用AIモデル: GPT-5
- 関連フェーズ: フェーズ5
- 関連仕様: `docs/PROJECT_SPEC.md` 18.4

## 背景

フェーズ4までのゲーム内文字はPyxel組み込みフォントを使用しており、日本語を表示できない。フェーズ5では14役の役名、読み、条件を初心者にも分かる形でゲーム内へ表示する必要がある。英語表記だけを追加すると、日本語の初心者向けガイドとゲーム内表示の対応が分かりにくく、今後チュートリアルを日本語化するときに別方式が必要になる。

Pyxel 2.9.8は`pyxel.Font`でBDFフォントを扱え、公式サンプルにUM+ 10px日本語BDFを含んでいる。

## 決定

Pyxel公式サンプルの`umplus_j10r.bdf`を`assets/fonts/`へ同梱する。字形データは変更せず、同梱先を示すBDFの`COMMENT`だけを追加する。フォント内の許諾文、出典、変更内容を`assets/fonts/README.md`へ記録する。

アプリ起動時にフォントを明示的に読み込み、日本語役名、読み、説明、点数単位、取得状態へ使用する。役一覧は1ページ1役とし、左右入力で14ページを切り替える。牌例は既存の16×16牌スプライトを8枚並べる。

PC版・スマートフォン版の`.pyxapp`へ、実行コードとともにフォントと許諾文を収録する。

## 理由

- Pyxelが公式に使用例を提供している方式で、デスクトップとWebの両方へ適用できる。
- 10pxの固定ビットマップは現在のドット絵と配色に合う。
- 役名だけの独自画像を作るより、今後の説明文やチュートリアルへ再利用しやすい。
- 1ページ1役にすることで、文字や牌画像を縮小せずPCとスマートフォンの両方で読める。

## 検討した代替案

### 英語だけで役一覧を拡張する

- 利点: 新しい資産が不要。
- 欠点: 日本語の役名と条件をゲーム内で確認できず、初心者向け資料との往復が必要になる。
- 不採用理由: 長期的な日本語UIの基盤にならない。

### 必要文字だけを画像や部分フォントへ焼き込む

- 利点: 配布サイズを小さくできる。
- 欠点: 文言追加のたびに文字集合と画像を再生成する必要がある。
- 不採用理由: 今後の日本語説明追加へ対応しにくい。

### TTFを同梱する

- 利点: サイズ指定や滑らかな表示が可能。
- 欠点: 現在の低解像度画面では固定BDFの方が表示を予測しやすい。
- 不採用理由: 10px BDFで必要な可読性を満たす。

## 影響

- コード: アプリ起動時のフォント読み込み、役カタログ、ページ式役一覧を追加する。
- テスト: 全役の説明と成立例、ページ操作、配布物へのフォント収録を確認する。
- UI: 役一覧だけ日本語フォントを使用し、既存ゲーム画面の英数字は変更しない。
- 将来の変更: 日本語のチュートリアルやヘルプも同じフォントを利用できる。
- 移行作業: Webビルド時に`assets/fonts/`を両配布物へコピーする。

## 確認事項

- フォントは約1MBであり、`.pyxapp`の配布サイズが増える。
- フォントの出典と許諾文を配布物から削除しない。
- PCとスマートフォンの実画面で、濁点、長音、漢字、点数単位が読めることを確認する。
