# ADR-0013: 基本和了と初期配牌フィルターを導入する

- 状態: 採用
- 日付: 2026-07-26
- 使用AIモデル: GPT-5
- 関連フェーズ: フェーズ5のプレイテスト調整
- 関連仕様: `docs/PROJECT_SPEC.md` の19節

## 背景

役を14種類へ増やした後も、完全ランダムな盤面とブロック、4牌単位の上書き、初回から役を必須とする条件が重なり、判断より初期状態の運で得点機会が決まる感覚が残った。ランダム性をなくさず、極端に不利な開始状態と無得点ゲームを減らす必要がある。

## 決定

通常形「3＋3＋2」または四対子が成立した行は、初回に限り役がなくても基本和了とし、設定可能な基本和了点50点を加算する。同じ行の2回目以降は従来どおり未取得役を1つ以上必要とする。

初期状態は盤面64牌、ドラ表示牌4牌、17ブロックを一単位として最大100回生成する。最初の3ブロックに含まれる12牌だけを候補とし、各行から通常形または四対子へ届く最小交換枚数を、牌種ごとの候補枚数を超えない多重集合探索で求める。既定では1〜2枚で届く行を1行以上、1〜3枚で届く行を3行以上必要とし、距離0の完成行は合格数へ含めない。

上限まで合格しない場合は、1〜2枚で届く行数、1〜3枚で届く行数、全8行の平均距離の順で最良候補を採用する。到達形がない行は平均比較で9枚相当とする。

## 理由

- 役を狙う価値を追加得点と再和了条件として維持しながら、最初の得点機会を増やせる。
- 盤面だけを補正せず初期状態全体を再生成するため、136枚と個体IDの整合性を既存設計のまま守れる。
- 候補12牌の多重集合だけを見ることで、実際の配置完全探索より開始処理を軽く保てる。
- しきい値と基本点を設定へ集約し、プレイテスト後の調整を局所化できる。

## 検討した代替案

### 初期盤面だけを部分的に差し替える

- 利点: 必ず近い行を作りやすい。
- 欠点: ドラ・ブロック・牌山との個体整合性管理が複雑になり、配牌が作為的に見えやすい。
- 不採用理由: 通常のランダム配牌に見える状態と136枚の一貫性を優先した。

### テトリミノ形と全配置座標まで探索する

- 利点: 実際に置ける攻略経路をより正確に評価できる。
- 欠点: 回転・複数ターン・上書き順まで探索範囲が広がり、開始時間と実装複雑度が大きくなる。
- 不採用理由: 今回は軽量評価だけを求める仕様であり、必要性はプレイテスト後に改めて判断する。

## 影響

- コード: `initial_deal.py`を追加し、`GameState.new()`が合格候補または最良候補を採用する。得点と行状態へ基本和了を追加する。
- テスト: 役なし初回和了、再和了防止、得点内訳、候補牌枚数、合否、再現シード、試行上限、最良候補、136枚保存を確認する。
- UI: 役一覧と初心者ガイドへ基本和了を追記し、和了通知で基本点、役点、ドラ点を分離する。
- 将来の変更: しきい値と基本点は設定で変更できる。配置座標を含む探索やブロック生成補正は今回追加しない。
- 移行作業: 保存データはハイスコアだけなので移行不要。

## 確認事項

プレイテストで1〜3ターン目の道筋、基本和了50点の重み、役を狙う価値、初期配牌の多様性、開始待ち時間を確認する。
