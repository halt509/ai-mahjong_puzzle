# ADR-0018: 中華風UI装飾とPC中央配置をコード描画する

- 状態: 採用
- 日付: 2026-08-06
- 使用AIモデル: GPT-5 / OpenAI組み込み画像生成
- 関連フェーズ: フェーズ7
- 関連仕様: `docs/PROJECT_SPEC.md` 21.6

## 背景

フェーズ7の牌は既存の16×16表示を正式採用したため、牌の視認性を維持したまま、表示枠と背景を麻雀らしく整える必要がある。中華風UIの方向案を比較し、雷紋風の角飾り、濃い木、古金、深緑の雲文様を使う方針が承認された。

PC版では、上部タイトル、盤面、情報欄、下部操作案内の左右位置が別々に決められており、デザイン枠を追加すると1pxの左右差や左端の不一致が目立つ状態だった。

## 決定

- 中華風の装飾は外部画像へ焼き込まず、Pyxelの矩形描画で再現する。
- 共通部品として背景雲、雷紋風角飾り付きパネル、中央留め飾り付きの線を用意する。
- 背景雲を先に描き、各画面の枠がその上へ重なることを許可する。
- 牌スプライト、ゲーム情報、操作、ルールは変更しない。
- PC版は盤面枠の左余白と情報枠の右余白を各7pxにし、両枠を一組として中央配置する。
- PC版の盤面枠と情報枠は上端を揃え、高さ132pxで統一する。
- PC版の論理解像度を256×192へ拡張し、プレイ画面のタイトル、盤面・情報欄、操作案内の各枠間へ2pxの上下余白を設ける。
- 操作案内の本文は枠から左右8px、上下6px以上離し、2行の間にも空きを設ける。
- PC版の情報欄は外枠の位置と幅を維持し、本文の左右余白を8px以上にする。
- PC版のタイトル枠を左右中央へ置き、操作案内枠の左端を盤面枠へ揃える。
- 操作案内枠の下部装飾は、画面中央から左右へ同じ長さで描く。
- スマートフォン版は牌の16×16表示と盤面位置を維持し、盤面外枠だけを情報枠と同じ左右8px・幅160pxへ広げて共通装飾を適用する。

## 理由

コード描画なら16色パレットと1px単位の位置を保証でき、PCとスマートフォンで同じ装飾部品を共有できる。装飾を背景と細い枠へ限定することで、中華風の印象を加えながら牌と文字の視認性を維持できる。

## 検討した代替案

### 背景と枠を1枚の画像として読み込む

- 利点: 複雑な文様を描きやすい。
- 欠点: PCとスマートフォンで別素材が必要になり、文字や枠位置の変更にも再制作が必要になる。
- 不採用理由: 現在の小さな画面では、コード描画の単純な文様で必要な密度を表現できるため。

### 朱色を主役にした高密度装飾

- 利点: 中華風の印象が強い。
- 欠点: 配置プレビュー、通知、三元牌の赤と競合しやすい。
- 不採用理由: プレイ情報より装飾が目立つため。

## 影響

- コード: `app.py`へ背景、角飾り、装飾パネル、中央線の共通描画を追加する。
- テスト: PCの左右余白、枠の高さ、操作案内左端、中央線の対称性、チュートリアル切り抜き座標を固定する。
- UI: タイトル、準備、ゲーム、説明、通知、川、役一覧、結果へ同じ装飾を適用する。
- 配布: PC版の論理解像度は256×176から256×192へ変わる。スマートフォン版の176×256は変わらない。
- 将来の変更: 点棒表示と演出強化は、この枠と配色を土台として別作業で追加する。
- 移行作業: チュートリアル画像とPC・スマートフォンWeb配布物を再生成する。

## 確認事項

- PC版でタイトル枠、盤面と情報欄、操作案内枠が左右中央へ揃っていることを確認する。
- PC版で盤面枠と情報枠の高さが揃い、操作文字が枠や中央線へ重ならないことを確認する。
- PC・スマートフォンで雲文様と角飾りが牌、文字、ボタン案内より目立たないことを確認する。
- 点棒表示、演出強化、正式BGMは後続作業として扱う。
