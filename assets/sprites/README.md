## 採用牌スプライト

`mahjong-tiles-placeholder.png`は、ゲームで正式採用した34種の16×16牌アトラスの見本です。実行時は同じ模様をコードから画像バンクへ生成します。

- フェーズ7の固定PNG試作は、模様が牌の影へ乗る箇所と視認性の低下があったため不採用としました。
- 萬子は数字と赤い`M`、筒子は藍・朱の点、索子は緑の竹で示します。
- 風牌は16×16での視認性を優先し、東を右、南を下、西を左、北を上の矢印で示します。
- 三元牌は従来の分かりやすさを残し、白・緑・赤の牌面として区別します。

## 案内キャラクター仮スプライト

`peacock-guide.png`は、フェーズ6の初心者向け説明で使用する
40×40の仮ピクセルスプライトです。

くじゃく絵文字の親しみやすさを参考に、丸い体、大きな目、短いくちばし、
小さな飾り羽を持つオリジナルキャラクターとして画像生成しました。
生成結果から背景を除去し、最近傍縮小した後、ゲーム内の16色パレットへ
変換しています。

正式キャラクターデザインはフェーズ7の対象です。
