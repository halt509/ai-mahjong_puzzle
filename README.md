# AI Mahjong Puzzle

作成日: 2026-07-24<br>
更新日: 2026-07-27<br>
使用AIモデル: GPT-5

Pyxelで制作する8×8牌上書きパズルゲームです。現在はフェーズ6を実装中で、初回チュートリアル、日本語の主要表示、改善したスマートフォン操作を含め、タイトルから17ターンのゲーム、14種類の役、カン・和了通知、結果画面まで通して遊べます。

牌表示は交換可能な16×16スプライトアトラスへ分離し、配色は深い緑、木、象牙、朱、金を中心とした麻雀卓のトーンにしています。

## 必要環境とセットアップ

- Python 3.11以降
- Pyxel 2.9以上、3未満
- テスト時のみpytest

PowerShellで次を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
```

## ゲームの起動

```powershell
python -m mahjong_puzzle.app
```

同じ盤面とブロック順を再現する場合はseedを指定できます。

```powershell
python -m mahjong_puzzle.app --seed 20260724
```

インストール後は次のコマンドでも起動できます。

```powershell
mahjong-puzzle
```

## PC・スマホブラウザでの簡易確認

フェーズ4の公開前確認用として、Pyxel Web Launcher向けの配布物を生成できます。

```powershell
python scripts\build_web.py
```

次の2つを生成します。

- `web/mahjong-puzzle.pyxapp`: PC向け横画面（256×176）
- `web/mahjong-puzzle-mobile.pyxapp`: スマートフォン向け縦画面（176×256）

どちらもゲームの実行に必要なPythonコードと日本語ビットマップフォントだけを含み、テスト、仕様書、開発用指示、コンセプト画像は含みません。ただし`.pyxapp`はZIP形式のため、同梱したゲームソースは閲覧可能です。

このリポジトリの`main`ブランチへ生成物をpushし、GitHubから公開取得できる状態にすると、PC版は次のURLで起動できます。

```text
https://kitao.github.io/pyxel/wasm/launcher/?play=halt509/ai-mahjong_puzzle/main/web/mahjong-puzzle&gamepad=enabled
```

スマートフォン縦画面版は次のURLです。

```text
https://kitao.github.io/pyxel/wasm/launcher/?play=halt509/ai-mahjong_puzzle/main/web/mahjong-puzzle-mobile&gamepad=enabled
```

PC版は従来どおりキーボードで操作できます。スマートフォン版は盤面を上、手番・得点・連続・ドラ・NEXTを下にまとめ、Pyxel Web Launcherのバーチャルゲームパッドで操作します。情報欄には`A:確定`、`X/B:回転`、`START:役`、`BACK:川`を常時表示します。ルール、ゲーム状態、牌スプライト、初回説明は共通で、端末ごとの操作だけを説明画面で切り替えます。盤面への直接タッチ操作は対象外です。

Web版のハイスコアと初回説明の確認状態はブラウザの`localStorage`へ保存します。保存キーはそれぞれ`ai_mahjong_puzzle.high_score`と`ai_mahjong_puzzle.tutorial_seen`です。同じブラウザと同じWeb Launcherオリジンでは再読込後も残りますが、ブラウザデータの削除やプライベートブラウズでは失われる場合があります。ランキングや端末間同期は行いません。デスクトップ版は別々のローカルJSONを使用します。

### 操作

| キー | 操作 |
|---|---|
| 矢印キー | ブロックを上下左右へ移動・役一覧のページ切り替え |
| `Z` | 反時計回りに90度回転 |
| `X` | 時計回りに90度回転 |
| `Space` / `Enter` | 現在位置へ配置 |
| `Tab` | 川の全履歴を開く・閉じる |
| `Y` | 役一覧を開く・閉じる |
| `H` | 遊び方を開く・閉じる |
| `R` | 結果画面から新しいゲームを開始 |
| `Esc` | 終了 |

### スマートフォン・ゲームパッド操作

| ボタン | 操作 |
|---|---|
| 十字キー | ブロックを上下左右へ移動・役一覧のページ切り替え |
| `X` | 反時計回りに90度回転 |
| `B` | 時計回りに90度回転・一覧や説明を閉じる |
| `A` | 配置・ゲーム開始・再スタート・説明の決定 |
| `Y` | 割り当てなし |
| `SELECT` / `BACK` | 川の全履歴を開く・閉じる |
| `START` | プレイ中は役一覧、タイトル・結果では遊び方 |

盤面の黄色い4マスが配置プレビューです。既存牌との衝突はなく、その位置の牌を上書きします。17個のブロックをすべて配置すると終了です。

横1行の8牌が通常形「3＋3＋2」または四対子になれば、役がなくても初回は基本和了として50点を獲得します。役とドラは追加得点です。同じ行で2回目以降に和了するには、その行でまだ取得していない役を1つ以上作る必要があります。

初回起動時は4ページの遊び方を表示します。左右入力でページを切り替え、`B`または`Esc`で閉じられます。`A`でも次へ進めますが、画面案内は左右と閉じる操作だけに絞ります。PCでは`H`、スマートフォンではタイトル・結果画面の`START`から後で読み直せます。操作ページには、実際のゲーム画面から盤面上部を原寸で切り抜いて表示します。案内役は、くじゃく絵文字を参考にしたオリジナルの仮ピクセルスプライトで、正式素材はフェーズ7の対象です。

タイトル画面は`Space`、`Enter`、`A`で開始します。カン・和了通知が出ている間は、いずれかの操作キーで通知だけを閉じます。その入力は盤面操作には使わず、次の入力から通常操作へ戻るため、意図しない配置を防げます。

ゲーム情報欄には次を表示します。PC版では盤面右、スマートフォン版では盤面下に配置します。

- `TURN`: 現在の手番
- `SCORE` / `得点`: 累計得点
- `COMBO` / `連続`: 連続和了ターン数。得点と同じ行に表示
- `BLOCK`: 現在操作中のブロック形
- `DORA`: 現在公開中のドラ表示牌を牌画像で表示
- `NEXT`: 次の3ブロック

通常画面へ川の牌や直前ターンの和了・カン数は表示しません。前者は川画面、後者は成立時の通知で確認します。PCでは`Tab`で全川履歴、`Y`で役一覧を確認できます。スマートフォンでは`SELECT` / `BACK`が川、`START`が役一覧です。役一覧は基本和了の説明と、1ページに1役ずつ日本語の役名、読み、条件、仮点数、8牌の成立例、取得状態を表示し、左右キーまたは十字キーで切り替えます。和了通知には基本和了点、役点、ドラ点、合計点を分けて表示します。

ハイスコアと初回説明の確認状態はOSのローカルアプリデータ領域へ`highscore.json`と`tutorial.json`として別々に保存します。保存場所を取得できない環境では`~/.local/share/ai_mahjong_puzzle/`を使います。読み書きに失敗した場合もゲームは継続し、タイトルまたは結果画面へ保存不可を表示します。

## 仮牌スプライト

実行時に`mahjong_puzzle.sprites`がPyxel画像バンク0へ、34種の16×16仮牌を固定座標で生成します。

風牌は16×16でも確実に区別できるよう、東を右、南を下、西を左、北を上の矢印で表現します。三元牌は白を白、發を緑、中を赤の塗りつぶしで表現します。透明色と暗い描線は別の色番号にしているため、索子の節やトゲが配置先の下地によって欠けることはありません。

- `assets/sprites/mahjong-tiles-placeholder.png`: 実際に使う仮アトラスの見本
- `assets/concepts/mahjong-tile-sprite-concept.png`: 正式素材を作る際のビジュアル方向案

正式素材へ交換するときは、`sprites.py`の`tile_sprite_uv()`が返す配置を維持して画像バンク0へ読み込めば、盤面ロジックやUIを変更せずに差し替えられます。並びは1段目が萬子、2段目が筒子、3段目が索子、4段目が東南西北白發中です。

## ターンのルール統合

`GameSession.place_active()`は1回の配置を次の順番で処理します。

1. 変更された横行を抽出
2. 全変更行の新規カンを先に検出
3. カン履歴を記録し、上限までドラ表示牌を追加公開
4. 新規カン行の和了をそのターンだけ保留
5. その他の変更行で通常形「3＋3＋2」と特殊形「四対子」を判定し、初回基本和了または未取得役を含む再和了候補を抽出
6. 和了行数とコンボを確定
7. 新しいカンドラを同ターンの別行へ適用
8. 各行の最高得点分解を採用し、行履歴と累計得点を更新

結果は`ResolvedTurn`として返り、配置、新規カン、公開表示牌、和了行、採用分解、現在役、新規役、ドラ枚数、得点内訳、ターン得点、累計得点を確認できます。

## フェーズ2の確定設定

- 136枚を初期盤面64枚、ドラ表示牌用4枚、配置ブロック用68枚へ配分
- 4牌ブロック17個、全17ターン
- 未公開ドラ表示牌候補は未使用牌のまま保持
- 次ブロックを3個表示
- ホールドなし
- 7種類を1回ずつ含む7バッグ方式
- 川は上書き牌、ターン、元座標、配置IDの全履歴を保持

## 初期配牌の事故防止

ゲーム開始時は盤面64牌、ドラ表示牌4牌、17ブロックをまとめてランダム生成し、最初の3ブロックにある12牌で各行を何枚交換すれば通常形または四対子へ届くか評価します。テトリミノの形や配置座標はこの軽量評価へ含めません。

合格条件は設定可能で、既定値は次のとおりです。

- 1〜2枚交換で届く行が1行以上
- 1〜3枚交換で届く行が3行以上
- 最初から完成済みの0枚交換行は合格数へ含めない
- 最大100回まで初期状態全体を再生成

100回で合格しない場合は、近い行数、3枚以内の行数、全行の平均距離の順で最良候補を採用します。`GameState.initial_deal_debug`で採用シード、試行回数、行別距離、合否、フォールバック使用有無を確認できます。

## フェーズ5の追加役

通常の「3＋3＋2」に、比較的作りやすい5役を追加しました。

- 字牌頭: 字牌の対子を頭にする
- 老頭頭: 1または9の数牌の対子を頭にする
- 二色同順: 異なる数牌種で同じ順子を2組作る
- 連続順子: 同じ数牌種で開始数字が1つずれた順子を2組作る
- 三色使い: 萬子・筒子・索子を1枚以上ずつ使う

四対子は「4種類×2枚」の特殊和了形として追加しました。同一牌4枚を2対子には数えず、新規カンがある行では従来どおりカンを優先します。四対子には字牌頭・老頭頭や面子構成役を複合せず、断么九・混一色・清一色・混老頭・三色使いのような8牌全体を見る役だけを複合します。

## 主要モジュール

- `tiles.py`: 牌種、一意ID付き物理牌、136枚生成
- `hand.py` / `yaku.py`: 3＋3＋2全分解、四対子、14役判定
- `yaku_catalog.py`: ゲーム内と日本語ガイドで共有する役説明・成立例
- `kan.py` / `dora.py`: カン候補とドラ計算
- `scoring.py` / `state.py`: 得点内訳、行履歴、コンボ状態
- `initial_deal.py`: 最初の3ブロックを使った交換距離と初期状態の合否
- `board.py`: 常に64枚を保持する8×8盤面と原子的上書き
- `tetromino.py`: 牌位置ごとの回転、7種類の形、7バッグ生成
- `river.py`: 捨て牌の全履歴
- `game.py`: 136枚配分、配置、ターン、終了、牌総数検証
- `integration.py`: カンから得点までのターン単位オーケストレーション
- `ui.py`: タイトル、説明、オーバーレイ、通知、結果への画面状態
- `tutorial.py`: PC・スマートフォンで共有する4ページの説明内容とページ状態
- `sprites.py`: 34種の固定アトラス座標と交換可能な仮牌生成
- `persistence.py`: ローカルハイスコアと初回説明進捗の検証・保存
- `web_main.py`: PC横画面版のPyxel Web Launcher起動エントリ
- `mobile_web_main.py`: スマートフォン縦画面版のPyxel Web Launcher起動エントリ
- `app.py`: 共通ゲーム操作と横・縦レイアウトを持つPyxel画面アダプター

## 仮定・保留事項

- 新規カンは変更行をすべて調べてから、行番号・牌種の安定順でドラ表示牌へ対応付けます。
- ドラ表示牌が4枚へ達した後も、新規カン履歴は記録します。
- 同一行・同一牌種のカンが履歴済みなら新規カンではないため、通常の和了判定へ進みます。
- 複数行同時和了倍率は、そのターンに和了した全行の得点へ適用します。
- 初期盤面の偶発的な役やカンは自動成立させません。
- 初期配牌の交換距離は候補12牌の枚数制限を守りますが、テトリミノの形と実配置座標は探索しません。
- 最小距離を求められない行は、フォールバックの平均距離比較で9枚相当として扱います。
- 回転時の壁蹴りは行いません。
- 混一色は「1種類の数牌と字牌の両方を含む」と解釈しています。
- 四対子は通常分解とは別の`FourPairsDecomposition`として保持し、全候補を同じ得点選択APIへ渡します。
- 四対子に字牌頭・老頭頭は複合しません。四対子では4対子のどれか1つを頭として選ばないためです。
- 通知を閉じた操作キーは誤配置防止のため消費し、次の入力から盤面操作へ戻ります。
- 通常画面には川を表示せず、全履歴を`Tab`または`BACK`の川画面へ集約しています。
- 仮牌は正式アートではなく、16×16での可読性と差し替え境界を確認するための叩き台です。
- 24px以上の牌へ変更する場合は、8×8盤面、サイドバー、論理解像度をまとめて再設計します。
- 効果音は外部音源を追加せず、Pyxelの音色・音列で生成しています。配置音は短いノイズ連打と低い打音を重ね、牌が触れる「ジャラッ」という質感を狙っています。
- ハイスコアは単一端末の最高得点だけを保存し、ランキングや複数プロフィールは扱いません。
- 初回説明を閉じた時点で既読として保存し、次回起動では自動表示しません。説明はタイトル・結果画面から再閲覧できます。
- チュートリアルのゲーム画面は固定スクリーンショットから盤面上部を原寸で切り抜いています。通常画面の配置を変更した場合は`assets/guides/tutorial-gameplay.png`も更新します。
- 案内キャラクターは画像生成を元に40×40・ゲーム内16色へ変換した仮スプライトです。正式デザイン、BGM、開始演出、得点単位変更はフェーズ7へ持ち越します。
- 難易度、ホールド、リプレイ、ランキング、正式アニメーションはフェーズ6対象外です。
