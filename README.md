# AI Mahjong Puzzle

作成日・更新日: 2026-07-24<br>
使用AIモデル: GPT-5

Pyxelで制作する8×8牌上書きパズルゲームです。現在はフェーズ3まで実装しており、盤面へテトリミノを配置すると、変更行のカン・ドラ・和了・再和了・コンボ・得点を一貫して解決します。

本格的な役表示、得点内訳画面、川の全履歴画面、演出、サウンド、結果画面はフェーズ4の範囲です。

## 必要環境とセットアップ

- Python 3.11以降
- Pyxel 2.9以上、3未満
- テスト時のみpytest

PowerShellで次を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
```

## ゲームの起動

```powershell
python -m mahjong_puzzle.app
```

同じ盤面とブロック順を再現する場合はseedを指定できます。

```powershell
python -m mahjong_puzzle.app --seed 20260724
```

インストール後は次のコマンドでも起動できます。

```powershell
mahjong-puzzle
```

### 操作

| キー | 操作 |
|---|---|
| 矢印キー | ブロックを上下左右へ移動 |
| `Z` | 反時計回りに90度回転 |
| `X` | 時計回りに90度回転 |
| `Space` / `Enter` | 現在位置へ配置 |
| `Esc` | 終了 |

盤面の黄色い4マスが配置プレビューです。既存牌との衝突はなく、その位置の牌を上書きします。17個のブロックをすべて配置すると終了です。

サイドバーには次を表示します。

- `SCORE`: 累計得点
- `COMBO`: 連続和了ターン数
- `DORA`: 現在公開中のドラ表示牌
- `RIVER`: 川の総牌数
- `LAST`: 直前ターンの和了行数と新規カン数
- `NEXT`: 次の3ブロック

画面ではPyxel組み込みフォントを使うため、数牌を`m1`・`p9`・`s5`、字牌を`E/S/W/N/P/F/C`で表示します。

```powershell

```

## ターンのルール統合

`GameSession.place_active()`は1回の配置を次の順番で処理します。

1. 変更された横行を抽出
2. 全変更行の新規カンを先に検出
3. カン履歴を記録し、上限までドラ表示牌を追加公開
4. 新規カン行の和了をそのターンだけ保留
5. その他の変更行で未取得役を含む和了候補を抽出
6. 和了行数とコンボを確定
7. 新しいカンドラを同ターンの別行へ適用
8. 各行の最高得点分解を採用し、行履歴と累計得点を更新

結果は`ResolvedTurn`として返り、配置、新規カン、公開表示牌、和了行、採用分解、現在役、新規役、ドラ枚数、得点内訳、ターン得点、累計得点を確認できます。

## フェーズ2の確定設定

- 136枚を初期盤面64枚、ドラ表示牌用4枚、配置ブロック用68枚へ配分
- 4牌ブロック17個、全17ターン
- 未公開ドラ表示牌候補は未使用牌のまま保持
- 次ブロックを3個表示
- ホールドなし
- 7種類を1回ずつ含む7バッグ方式
- 川は上書き牌、ターン、元座標、配置IDの全履歴を保持

## 主要モジュール

- `tiles.py`: 牌種、一意ID付き物理牌、136枚生成
- `hand.py` / `yaku.py`: 3＋3＋2全分解と初期8役
- `kan.py` / `dora.py`: カン候補とドラ計算
- `scoring.py` / `state.py`: 得点内訳、行履歴、コンボ状態
- `board.py`: 常に64枚を保持する8×8盤面と原子的上書き
- `tetromino.py`: 牌位置ごとの回転、7種類の形、7バッグ生成
- `river.py`: 捨て牌の全履歴
- `game.py`: 136枚配分、配置、ターン、終了、牌総数検証
- `integration.py`: カンから得点までのターン単位オーケストレーション
- `app.py`: Pyxel描画と入力の画面アダプター

## 仮点数

点数は`ScoringConfig`へ集約してあり、ゲームバランス確定値ではありません。

| 要素 | 仮値 |
|---|---:|
| 全順子 | 100 |
| 全刻子 | 200 |
| 断么九 | 100 |
| 一盃口 | 200 |
| 混一色 | 300 |
| 清一色 | 500 |
| 混老頭 | 400 |
| 役牌 | 200 |
| ドラ1枚 | 50 |
| 2役目以降の複合役1つ | 50 |
| 同一行の過去和了1回 | 100 |
| 2連続目以降の1連続 | ×0.25を加算 |
| 2行目以降の同時和了1行 | ×0.5を加算 |

倍率計算で端数が生じるカスタム設定では、すべての倍率を掛けた最後に小数点以下を切り捨てます。

## 仮定・保留事項

- 新規カンは変更行をすべて調べてから、行番号・牌種の安定順でドラ表示牌へ対応付けます。
- ドラ表示牌が4枚へ達した後も、新規カン履歴は記録します。
- 同一行・同一牌種のカンが履歴済みなら新規カンではないため、通常の和了判定へ進みます。
- 複数行同時和了倍率は、そのターンに和了した全行の得点へ適用します。
- 初期盤面の偶発的な役やカンは自動成立させません。
- 回転時の壁蹴りは行いません。
- 混一色は「1種類の数牌と字牌の両方を含む」と解釈しています。
- 現行8役では複数分解によって役集合が異なる具体例を確認できていませんが、分解候補ごとの評価APIは維持しています。
- 牌スプライト、配色テーマ、役・カン演出、詳細な得点理由の画面表示はフェーズ4で扱います。
